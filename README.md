# Online-Learning-Platform-Analysis
 ##  📌Project overview
This project presents an interactive **Excel dashboard** developed to analyze online learning platform usage and generate meaningful insights into learner behavior and engagement. The dashboard provides a comprehensive view of key metrics, including total users, average learning hours, completion rates, satisfaction scores, platform usage, and device distribution.
Using **SQL** for data analysis and aggregation and **Excel PivotTables, slicers, and charts** for visualization, the dashboard enables users to explore learner demographics, compare platform usage and completion rates, analyze learning hours by role, identify content preferences, and evaluate learning purposes. The dashboard also provides interactive filtering by age group, role, platform, device, and learning purpose, helping users identify patterns in learner engagement, content preferences, platform adoption, and course completion.
## 📂 Dataset
The dataset used in this project was sourced from **Kaggle** and contains online learning platform usage data, including user demographics, roles, learning platforms, learning devices, weekly learning hours, learning purposes, content preferences, completion rates and satisfaction scores.
| Column Name             | Description                                          |
| ----------------------- | ---------------------------------------------------- |
| user_id                 | Unique identifier for each learner                   |
| age_group               | Age category of the learner                          |
| role                    | Role of the learner, such as student or professional |
| primary_platform        | Primary online learning platform used                |
| learning_device         | Device used for learning                             |
| hours_per_week          | Average number of hours spent learning per week      |
| learning_purpose        | Primary purpose for using the learning platform      |
| content_type_preference | Preferred type of learning content                   |
| completion_rate_percent | Percentage of course or learning content completed   |
| satisfaction_score      | Learner satisfaction rating                          |
## 🛠️Tools Used
* **SQL** – Data analysis, aggregation, KPI calculations, and extracting meaningful insights
* **Microsoft Excel** – Data analysis, dashboard development, and data visualization
* **PivotTables & PivotCharts** – Summarizing learner data and creating interactive visualizations
## 📊 Key KPIs
* **Total Users**
* **Average Learning Hours**
* **Average Completion Rate**
* **Average Satisfaction Score**
## ➕ Additioal Features
### 🎛️ Slicers
* **Role** – Filter the dashboard based on learner roles.
* **Primary Platform** – Filter analysis based on the learning platform used.
* **Learning Device** – Filter users based on their learning device.
* **Learning Purpose** – Filter dashboard insights based on the learner's purpose.
## 🎯 Business Objectives
* Analyze overall **learner engagement and platform usage**.
* Understand the distribution of users across different **age groups and roles**.
* Identify the most frequently used **learning platforms and devices**.
* Analyze **average learning hours** to understand learner engagement levels.
* Compare **completion rates** across platforms and learning purposes.
* Identify the most preferred **content types** among learners.
* Analyze **satisfaction scores** to understand learner experience.
* Evaluate differences in learning behavior across **user roles and demographics**.
* Provide interactive filtering through **Excel slicers** for deeper analysis.
* Support **data-driven decisions** by presenting learner behavior and engagement insights through an interactive dashboard.
